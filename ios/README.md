# Kamron APP на iPhone

Приложение — веб-страница на GitHub Pages. Здесь только оболочка: иконка
на домашнем экране, своё окно и постоянное хранилище. Логика внутри
страницы, поэтому после правок в приложении новая сборка не нужна — достаточно
задеплоить страницу, и приложение подхватит её при следующем открытии.

## Сборка

Двойной щелчок по файлу **«Собрать проект.command»** в этой папке. Он
доставит xcodegen, если его нет, соберёт файл проекта и откроет Xcode.

То же вручную:

```sh
brew install xcodegen          # один раз
cd "/Users/macbook/Desktop/Kamron APP/ios"
xcodegen generate
open KamronAPP.xcodeproj
```

Дальше в Xcode:

1. Выбрать цель **KamronAPP** → вкладка **Signing & Capabilities**.
2. В **Team** выбрать свою учётную запись Apple. Если её нет:
   Xcode → Settings → Accounts → **+** → Apple ID.
3. Подключить iPhone кабелем, выбрать его в списке устройств сверху.
4. Нажать **Run** (⌘R).
5. На iPhone: Настройки → Основные → VPN и управление устройством →
   доверять своему профилю разработчика. Это требуется один раз.

## Про срок жизни сборки

С бесплатной учётной записью Apple подпись живёт **7 дней**: через неделю
приложение перестанет открываться, и его нужно запустить из Xcode заново.
Платная учётная запись разработчика (99 $ в год) продлевает срок до года.

Без Xcode есть путь без срока годности: открыть
`https://kslmvv.github.io/kamron-app/` в Safari → «Поделиться» →
«На экран „Домой“». Иконка и полноэкранный режим те же, срок не истекает.

## Данные

Хранилище этого приложения отдельное от Safari — данные из браузера сюда
сами не перейдут. Если в Safari уже что-то накоплено: в приложении
Настройки → скачать копию данных, затем в новой сборке — загрузить копию.

## Виджет и живое уведомление

В сборке три поверхности помимо самого приложения:

* **Виджет «День»** — маленький и средний, на домашнем экране. Показывает
  текущий блок, живой остаток времени и три ближайших дела.
* **Живое уведомление** — карточка на экране блокировки с отсчётом до
  конца блока и кнопкой «Сделал».
* **Динамический остров** — то же самое в свёрнутом и развёрнутом виде.

### Откуда виджет берёт данные

Хозяин данных — страница, виджет только показывает. Страница кладёт
снимок дня в общий ящик (App Group), виджет его читает, а нажатие
«Сделал» возвращается обратно заявкой, которую страница применяет при
следующем открытии приложения. Честность времени проверяется в странице
по тем же правилам: отметка, сделанная после того как дело прошло, не
засчитывается — через виджет блокировку не обойти.

### Что нужно включить в Xcode

App Group **не выдаётся бесплатной учётной записи**. С бесплатной
подписью приложение соберётся, но виджет честно напишет, что данных нет.
Для рабочего виджета нужна платная учётная запись разработчика (99 $ в
год), и в ней:

1. На developer.apple.com → Identifiers создать App Group
   `group.com.kslmvv.kamronapp`.
2. В Xcode у цели **KamronAPP** и у цели **KamronWidgetsExtension**:
   Signing & Capabilities → **+ Capability** → App Groups → поставить
   галочку на этой группе.
3. У цели **KamronAPP** добавить **Push Notifications**, если позже
   захочется обновлять живое уведомление с сервера.

Файлы `*.entitlements` уже лежат в репозитории и прописаны в `project.yml`
— Xcode подхватит их сам, останется только отметить галочки.

### Анимация питомца в виджете

Непрерывной анимации у виджетов не бывает. Движение собрано из трёх
источников:

* **раз в минуту** — кадр позы питомца из заранее отрисованного таймлайна
  (лимит обновлений при этом не тратится);
* **каждую секунду** — таймер и полоса прогресса, их система считает сама;
* **на событии** — смена лица и цвета, когда блок закрыт или упущен.

### Ограничение живого уведомления

Уведомление запускает и обновляет приложение, поэтому пока оно закрыто,
цифры в карточке не меняются — но отсчёт времени идёт, его ведёт система.
Чтобы карточка обновлялась и при закрытом приложении, нужен push с
сервера на токен уведомления (ActivityKit push). Это следующий шаг, если
понадобится.
