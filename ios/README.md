# Kamron APP на iPhone

Приложение — веб-страница на GitHub Pages. Здесь только оболочка: иконка
на домашнем экране, своё окно и постоянное хранилище. Логика внутри
страницы, поэтому после правок в приложении новая сборка не нужна — достаточно
задеплоить страницу, и приложение подхватит её при следующем открытии.

## Сборка

Двойной щелчок по файлу **«Собрать проект.command»** в этой папке. Он
доставит xcodegen, если его нет, соберёт файл проекта и откроет Xcode.

То же вручную:

```sh
brew install xcodegen          # один раз
cd "/Users/macbook/Desktop/Kamron APP/ios"
xcodegen generate
open KamronAPP.xcodeproj
```

Дальше в Xcode:

1. Выбрать цель **KamronAPP** → вкладка **Signing & Capabilities**.
2. В **Team** выбрать свою учётную запись Apple. Если её нет:
   Xcode → Settings → Accounts → **+** → Apple ID.
3. Подключить iPhone кабелем, выбрать его в списке устройств сверху.
4. Нажать **Run** (⌘R).
5. На iPhone: Настройки → Основные → VPN и управление устройством →
   доверять своему профилю разработчика. Это требуется один раз.

## Про срок жизни сборки

С бесплатной учётной записью Apple подпись живёт **7 дней**: через неделю
приложение перестанет открываться, и его нужно запустить из Xcode заново.
Платная учётная запись разработчика (99 $ в год) продлевает срок до года.

Без Xcode есть путь без срока годности: открыть
`https://kslmvv.github.io/kamron-app/` в Safari → «Поделиться» →
«На экран „Домой“». Иконка и полноэкранный режим те же, срок не истекает.

## Данные

Хранилище этого приложения отдельное от Safari — данные из браузера сюда
сами не перейдут. Если в Safari уже что-то накоплено: в приложении
Настройки → скачать копию данных, затем в новой сборке — загрузить копию.

## Виджет и живое уведомление

В сборке три поверхности помимо самого приложения:

* **Виджет «День»** — маленький и средний, на домашнем экране. Показывает
  текущий блок, живой остаток времени и три ближайших дела.
* **Живое уведомление** — карточка на экране блокировки с отсчётом до
  конца блока и кнопкой «Сделал».
* **Динамический остров** — то же самое в свёрнутом и развёрнутом виде.

Живое уведомление и остров работают **на бесплатной учётной записи** без
единой настройки: данные туда кладёт само приложение через ActivityKit, а
кнопка «Сделал» выполняется в процессе приложения. Никаких разрешений от
Apple для этого не нужно.

Отдельного внимания требует только виджет на домашнем экране.

## Виджет без платной учётной записи

Виджет — отдельная программа со своей песочницей: напрямую он не видит
ничего из того, что записало приложение. Путей два.

### Путь 1 — через сервер (работает бесплатно)

Страница и так кладёт день на сервер Jarvis. Виджет его оттуда и берёт.
Ничего подписывать не нужно, достаточно одного ключа.

1. В Railway у сервиса **jarvis** добавить переменную `WIDGET_TOKEN` —
   придумайте длинную случайную строку. Это отдельный ключ: им
   открывается только сегодняшний день и приём отметки, но не переписка,
   не резервные копии и не расходы.
2. На маке скопировать заготовку и вписать то же самое:

   ```sh
   cd "/Users/macbook/Desktop/Kamron APP/ios"
   cp Shared/Secrets.example.swift Shared/Secrets.swift
   ```

   В `Shared/Secrets.swift`:

   ```swift
   static let server = "https://jarvis-production-d62d.up.railway.app"
   static let widgetToken = "то же, что в WIDGET_TOKEN"
   ```

   Файл в репозиторий не попадает — он в `.gitignore`.
3. Собрать как обычно: двойной щелчок по **«Собрать проект.command»**.

Чем этот путь хуже: виджет ходит в сеть, поэтому обновляется не мгновенно
и в самолёте показывает последний загруженный день. Для режима дня этого
достаточно — минутная точность тут не нужна.

### Путь 2 — через общий ящик (App Group)

Лучше: день не выходит в сеть, виджет работает офлайн и обновляется
сразу. Но App Group подписывается не всякой учётной записью — обычно
нужна платная (99 $ в год). Если она есть:

1. На developer.apple.com → Identifiers → App Groups завести
   `group.com.kslmvv.kamronapp`.
2. Собрать с другим описанием:

   ```sh
   ./"Собрать проект.command" --app-group
   ```

   или вручную: `xcodegen generate --spec project.appgroup.yml`.
3. В Xcode у обеих целей, **KamronAPP** и **KamronWidgetsExtension**:
   Signing & Capabilities → App Groups → галочка на этой группе.

Если сборка упадёт на подписи с жалобой на
`com.apple.security.application-groups` — учётная запись App Group не
даёт. Соберите обычным `project.yml` и настройте путь 1.

Попробовать второй путь стоит в любом случае: он занимает пять минут, а
Apple периодически меняет то, что доступно бесплатным учётным записям.
Виджет сам разберётся, какой путь ему достался, и скажет прямо, если не
достался ни один.

### Откуда виджет берёт данные

Хозяин данных — страница, виджет только показывает. Нажатие «Сделал»
возвращается заявкой: через общий ящик или через ту же очередь на
сервере, куда складывает надиктованное бот. Страница применяет её при
следующем открытии и проверяет время по своим правилам — отметка,
сделанная после того как дело прошло, не засчитывается. Через виджет
честную блокировку не обойти.

### Анимация питомца в виджете

Непрерывной анимации у виджетов не бывает. Движение собрано из трёх
источников:

* **раз в минуту** — кадр позы питомца из заранее отрисованного таймлайна
  (лимит обновлений при этом не тратится);
* **каждую секунду** — таймер и полоса прогресса, их система считает сама;
* **на событии** — смена лица и цвета, когда блок закрыт или упущен.

### Ограничение живого уведомления

Уведомление запускает и обновляет приложение, поэтому пока оно закрыто,
цифры в карточке не меняются — но отсчёт времени идёт, его ведёт система.
Чтобы карточка обновлялась и при закрытом приложении, нужен push с
сервера на токен уведомления (ActivityKit push). Это следующий шаг, если
понадобится.
