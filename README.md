# Kamron APP

Личное приложение одного дня: оно не ведёт список задач, а держит режим.

Открывается на [kslmvv.github.io/kamron-app](https://kslmvv.github.io/kamron-app/), ставится
на домашний экран как обычное приложение и работает офлайн. Данные лежат только
на устройстве.

## Из чего состоит день

**Питомец.** Главный экран занимает существо, которое живёт само: дышит, меняет
форму, моргает, следит глазами за пальцем и открывает рот, когда говорит. У него
пятнадцать состояний — от сна до бешенства — и он никогда не ругает просто так:
у каждого настроения есть кнопка «почему?» с разбором причины и конкретным
указанием, что делать прямо сейчас. Он растёт от реально закрытых дней и слабеет,
когда их нет.

**Честное время.** Дело отмечается, только пока оно идёт, плюс пятнадцать минут
запаса. Прошло — становится упущенным насовсем и красным в списке. Будущее
заблокировано. Систему нельзя обмануть, «досдав» день вечером, — иначе режим
теряет смысл.

**Фокус.** Одно дело во весь экран: таймер до конца, кольцо прогресса и питомец,
который смотрит. Досрочный выход записывается.

**Разбор дня.** Вечером приложение спрашивает одно: почему. Три кнопки — не успел,
забыл, не захотел. Из этих ответов через пару недель собирается картина, где
именно утекает время.

**Выводы.** Не проценты, а наблюдения: худший день недели, доля потерь после
восьми вечера, слабая привычка, самая частая названная причина.

**Напоминания.** Приложение само стучится за десять минут до дела, в начале
свободного окна, когда дело вот-вот закроется, и вечером на разбор.

**Резервная копия.** Состояние целиком уезжает на сервер при каждом изменении,
сервер держит десять последних копий. Если историю Safari стёрли, приложение
открывается пустым и молча возвращает данные само. Если стёрся и ключ связи,
бот по команде `/связь` присылает ссылку, которая возвращает всё одним
нажатием.

Ещё внутри: расписание университета с редактором, привычки с несколькими
отметками в день, задачи на любую дату, календарь с кольцами по дням и чат,
который отвечает по данным дня.

## Разработка

```
npm install
npm run serve     # локальный сервер
npm run build     # проставить версию в sw.js и app.js
npm run check     # поиск неопределённых ссылок в app.js
npm test          # сквозной тест в браузере (102 проверки)
npx playwright install chromium   # один раз, если браузера нет
```

Приложение — один классический скрипт `app.js`, один `styles.css` и `index.html`.
Сборки нет намеренно: страница должна открываться и напрямую из файла, где
ES-модули запрещены политикой источников.

Тест подменяет часы страницы и проверяет то, что ломается молча: блокировку
упущенного, фокус-режим, разбор дня, правку расписания, календарь, историю чата
и то, что состояние переживает перезагрузку.

### Структура

```
index.html, styles.css, app.js   приложение
anim/                            собранные сцены занятий питомца
sw.js, manifest.webmanifest      офлайн и установка на телефон
icons/, logos/                   знак К
tests/                           сквозной тест
tools/                           версия, иконки, локальный сервер, полнота сборки
tools/scenes/                    исходники сцен: питомец и описания сцен
legacy/                          прошлая версия приложения (не подключена)
server/                          сервер Jarvis на Railway
jarvis-bot/                      голосовой помощник в Telegram
telegram-call/                   спайк настоящих звонков (не в работе)
ios/                             обёртка WKWebView, виджет, живое уведомление
```

Сцены собираются отдельно: `python3 tools/scenes/build.py` переписывает
`anim/scenes.js` и `anim/scenes.css` из исходников в `tools/scenes/`.
