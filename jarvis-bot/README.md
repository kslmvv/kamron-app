# Jarvis в Telegram

Голосовой помощник по режиму дня. Наговариваешь голосовое — он отвечает
голосом, а то, что ты ему продиктовал, появляется в приложении.

## Что делает

- слышит голосовое и отвечает голосовым;
- на текст отвечает текстом — озвучка стоит денег, а читать в этот момент ты можешь;
- записывает в приложение задачи, дела по времени и заметки, отмечает сделанное;
- утром и вечером пишет сам: план на день и итог;
- в течение дня напоминает голосом: за десять минут до дела, в начале
  свободного окна и когда дело вот-вот закроется без отметки;
- считает расход и останавливается, упёршись в дневной потолок.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `AI_ENABLED` | **по умолчанию `0` — платные вызовы выключены.** `1` включает мозг, расшифровку и озвучку |
| `OPENAI_API_KEY` | ключ OpenAI |
| `JARVIS_URL` | адрес сервера приложения |
| `JARVIS_TOKEN` | его `APP_ACCESS_TOKEN` |
| `MAX_DAY_COST` | потолок расхода за сутки, по умолчанию 0.25 |
| `MAX_VOICE_SECONDS` | предел длины голосового, по умолчанию 120 |
| `MAX_REPLY_CHARS` | предел длины ответа, по умолчанию 420 |
| `BRAIN_MODEL` / `STT_MODEL` / `TTS_MODEL` / `TTS_VOICE` | какие модели использовать |
| `MORNING_AT` / `EVENING_AT` / `TIMEZONE` | когда бот пишет сам |
| `NUDGE_ENABLED` | `0` выключает напоминания по ходу дня |
| `NUDGE_MAX` | сколько напоминаний в сутки, по умолчанию 8 |
| `NUDGE_BEFORE_MIN` | за сколько минут предупреждать, по умолчанию 10 |
| `QUIET_FROM` / `QUIET_TO` | когда бот молчит, по умолчанию с 23:00 до 06:20 |
| `SCHEDULE_ENABLED` | `0` выключает утреннюю и вечернюю сводки |
| `DATA_DIR` | том для памяти бота, по умолчанию `/data` |

Том обязателен: в нём лежат владелец, расход за сутки и отметки об
отправленных сводках. Без него после каждого деплоя бот забудет, кому он
принадлежит, и обнулит счётчик.

## Как устроено

Голосовое приходит в OGG/Opus, перекладывается в mp3 и уходит на
распознавание. Текст идёт в модель вместе со снимком дня из приложения и
списком инструментов. Если модель вызвала инструмент — запись уходит в
очередь на сервере, приложение заберёт её при следующем открытии. Ответ
озвучивается, перекладывается обратно в OGG/Opus (Telegram показывает
голосовым только его) и уходит голосовым с текстом в подписи.

Напоминания бот считает по снимку дня из приложения: если снимок не за
сегодня, он молчит — лучше промолчать, чем напомнить о вчерашнем плане.
Каждое событие дня отрабатывает один раз, отметка лежит на диске.

Первый, кто напишет боту, становится владельцем — он записывается на диск,
остальные чаты игнорируются.

## Проверка

```
cd jarvis-bot && python3 -m tests.e2e
```

Поднимает поддельные Telegram, OpenAI и сервер приложения и прогоняет весь
путь без единого платного запроса: кодеки, запись в приложение, лимиты.

## Выключатель платного

`AI_ENABLED` по умолчанию `0`, и бот в этом состоянии не делает ни
одного платного запроса: ни к мозгу, ни к расшифровке, ни к озвучке.
Проверяется он в `state.can_spend()` — в одном узком месте, через
которое проходят все три, чтобы платный вызов, добавленный через
полгода, не прошёл мимо.

Выключено по умолчанию нарочно. Выключатель, включённый по умолчанию,
возвращается сам: при переразвёртывании, при переносе сервиса, при
пересоздании переменных — и расход возобновляется молча.

Что при этом происходит:

* На сообщение бот отвечает, что ИИ выключен и как его включить.
* Напоминаний по ходу дня и утренней с вечерней сводок нет вовсе —
  иначе каждое утро приходило бы «ИИ выключен».
* `/здоровье` показывает `ииВключен`.

Включить обратно: `AI_ENABLED=1`.

**Остановить расход немедленно, не дожидаясь развёртывания этого кода,**
можно только одним способом — убрать `OPENAI_API_KEY` (или переименовать
переменную, чтобы значение не потерять). Запрос без ключа отвергается
раньше, чем что-то посчитается. Варианта с `MAX_DAY_COST=0` мало: у
соседнего сервиса звонков озвучка этим лимитом не прикрыта.
